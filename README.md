
# Foodie Haven 

Foodie Haven is a simple and responsive restaurant website created using HTML and CSS. It displays restaurant information, different food items, special offers and contact details.

## About the Project

I created this website to practice my HTML and CSS skills. The website has a simple design and works on desktop, tablet and mobile screens.

## Features

- Home section
- About section
- Food menu with images
- Special offer section
- Social media links
- Quick links
- Footer with contact information
- Responsive design

## Technologies Used

- HTML5
- CSS3

## Concepts Used

- Semantic HTML
- Flexbox
- CSS Grid
- Media Queries
- Hover Effects
